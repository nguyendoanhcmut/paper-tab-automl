Adaboost model can be used for the effluent COD prediction at

the model were optimized in the training set (70%) using the root mean 
square error (RMSE) objective function. The trained model was regres­
sion simulated on the test set (30%) for the effluent COD analysis. The R2 
on the test set reached 0.9051, and the RMSE was 9.88 mg/L. Except for
