The deep SHAP algorithm is utilized for interpreting the predictions 
made by deep learning models, in which, a baseline value, typically the 
average of input features or a zero-value matrix, is selected as a refer­
ence point to evaluate the relative contribution of each feature to the 
output, and assess how it impacts the output in relation to this baseline 
value. For deep neural networks, the interpretation proceeds layer by 
layer from input to output layers, enabling more precise quantification 
of the contribution of each node or feature. Ultimately, every input 
feature is assigned a SHAP value that quantifies its impact on the 
model’s output (Wang et al., 2022).
