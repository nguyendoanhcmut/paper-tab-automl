2.3.3. LSTM model 
MLP and LSTM have the same input and output layer properties for 
regression prediction. Three hidden layers are in the LSTM model, the 
first is an LSTM layer with 45 memory units, and the rest are fully 
connected layers with 140 neurons in each. The activation functions for 
each hidden layer were, in the order, ReLU, Tanh, and Tanh. 
Each unit in the LSTM layer is tasked with processing and storing 
data over time. It comprises several vital components, including input 
gates, forget gates, output gates, and memory cells. Eqs. (11)–(15) define 
how the input, previous hidden state, and previous cell state are com­
bined and transformed to produce the output hidden state and updated 
cell state for each time step in the sequence.

The LSTM model is organically structured to handle sequences, and 
its architecture can evaluate time steps to identify temporal links and 
patterns within data. In this investigation, LSTM was employed in an 
unorthodox method. Typically, the time steps in an LSTM model reflect 
instances or points in a series, however, in this configuration, the time 
step was purposefully set to 1. As a result, each feature in the dataset was 
regarded as a unique instance as opposed to a single point in a sequence. 
This indicates that the LSTM configuration merely captured the current 
value of the feature without utilizing the model’s temporal sequencing 
capability. This method was chosen expressly to compare the prediction 
skills of an LSTM, which normally processes sequences, with the MLP on 
a non-sequential data set-up. The LSTM model adopted Adam as the 
optimizer with a learning rate of 0.0003677. Dropout and weight decay 
were performed on each hidden layer with a dropout rate of 0.1663 and 
weight decay of 0.0004726.
