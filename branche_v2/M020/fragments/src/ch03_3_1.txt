2.3.1. Hyperparameters optimization (HPO) 
The model development process is illustrated in Fig. 2. Across all 
machine learning techniques, hyperparameters are vital to model per­
formance. The values of hyperparameters are determined prior to the 
start of the learning process (Agarwal et al., 2023). In the case of NNs, 
these include parameters such as the learning rate, number of layers, 
number of neurons in each layer, etc. Hyperparameters can have a sig­
nificant impact on a model’s ability to learn from data and generalize to 
new, unseen data, as well as the model’s overall performance, efficiency, 
and generalizability. It is essential for the development of any machine 
learning model that these hyperparameters are effectively tuned. To 
obtain the best performance, the Optuna framework (Akiba et al., 2019) 
in Python was used to optimize the hyperparameters for the MLP, 
including the number of hidden layers, number of neurons in the hidden 
layers, activation functions in each hidden layer, optimizers and their 
learning rate during the training process, the dropout rate for each 
hidden layer, weight decay as the L2 regularization, and loss function. In 
addition to optimizing the previously described hyperparameters, the 
number of memory units was improved in the LSTM model. Table 3 
presents the available alternatives for each hyperparameter. As its 
default approach for HPO, Optuna involves employing the Tree- 
structured Parzen Estimator (TPE) algorithm. TPE is a variation of the 
Bayesian optimization technique for effectively exploring the search 
space and identifying potential hyperparameter combinations (J. Li 
et al., 2022). Notably, the prediction performances of the MLP and LSTM 
models based on the regression concept were assessed using the coeffi­
cient of determination (R2), as stated in Eq. (2), Therefore, the HPO aims 
to maximize R2 to achieve the highest prediction accuracy.

The epochs and batch sizes are vital parameters affecting the 
learning process. Each epoch was one full run through the entire dataset 
during the training. Before training, the number of epochs was a 
hyperparameter requiring definition. It is computationally expensive to 
update the weights after each training sample in NN training; therefore, 
the batch size is another hyperparameter to be specified (Masters and 
Luschi, 2018). Based on the dataset size and train-test dataset split of the 
TMP prediction, the batch size and epochs in the HPO process were set to 
32 and 1000, respectively, which were the same as the MLP and LSTM 
prediction models that followed. 
Through using the backpropagation (BP) algorithm, the MLP and 
LSTM models were trained. An optimizer was used in the BP training to 
alter the weights and biases of the NN depending on the calculated 
gradients. An optimizer is primarily used to minimize errors or loss 
functions during training (Sun, 2019). The HPO was conducted using the 
Adam, RMSProp, and AdaDelta optimizer choices. In addition, the HPO 
improves the learning rate, which is a critical hyperparameter in opti­
mization algorithms. During NN training, the learning rate controls the 
step size at which the optimizer modifies the weights and biases. The 
learning rate regulates the magnitude of model updates and may sub­
stantially affect the convergence and performance of the model (Smith, 
2017).
