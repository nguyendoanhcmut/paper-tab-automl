2.4. Model interpretability analysis 
Interpretability in ML refers to the capacity to comprehend and 
explain the decisions and reasoning behind machine-learning models. 
Despite their broad acceptance, ML models are mostly opaque. Under­
standing the causes of predictions is crucial for assessing trust and 
determining whether one intends to act based on a prediction or 
implement a new model (Lipton, 2017). In the membrane fouling pre­
diction assignment, interpretability analysis may explain the model and 
provide insights into fouling parameters to facilitate inspection. The 
SHapley Additive exPlanations (SHAP) (Lundberg and Lee, 2017), a 
state-of-the-art interpreting technique, was applied to the MLP model to 
evaluate the interpretability and examine the impact of input parame­
ters on membrane fouling.

quantifying the significance of each feature in the prediction:

where ϕi (f,x) represents the SHAP value of feature i for a prediction 
made by model f on an instance x; N is the set of all features; S is a 
coalition of features not including feature i; f (S) is the prediction made 
using the model on an instance x with features in S; f (S{i}) is the pre­
diction made using the model on an instance x with the features in S plus 
feature i. The SHAP value of a feature is calculated by considering all 
possible feature coalitions and their marginal contributions. To validate 
the reasonableness of the membrane fouling prediction model, and ac­
quire a better understanding of how the input parameters influence TMP 
modification, the feature importance, global interpretability, and local 
interpretability of the MLP regression model based on SHAP values were 
investigated.
