3.2
Prompt Adaptation Memory
While the LLM’s pretrained knowledge provides a strong prior over feature programs, effective search requires the pro-
posal mechanism to adapt online to each island’s evolving landscape. Without adaptation, the LLM repeatedly proposes
programs in regions already known to be unproductive, wasting evaluation budget. We introduce Prompt Adaptation
Memory (PAM), a lightweight per-island mechanism that continuously shapes the LLM’s proposal distribution from
accumulated search experience without any parameter update. PAM operates through three coordinated update rules
applied after every generation.
