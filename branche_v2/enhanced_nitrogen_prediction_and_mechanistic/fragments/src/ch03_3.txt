2.3.1. Machine learning algorithms

This study applies six machine learning models to simulate effluent 
water quality. Gradient boosting decision trees (GBDT) is an ensemble 
learning method that sequentially builds multiple weak decision trees, 
with each tree correcting the errors of the previous one (Niu et al., 
2023). Light gradient boosting machine (LightGBM) is a variant of 
GBDT, using a histogram-based approach to speed up training and 
improve efficiency (Chang et al., 2022). Random forest (RF) is an inte­
grated approach to building multiple decision trees, each trained on a 
random subset of data and features (Lai et al., 2025). XGBoost is another 
gradient-boosting algorithm that optimizes performance and computa­
tional efficiency using techniques like regularization and parallelization 
(Yaqub and Lee, 2022). Adaptive boosting (AdaBoost) is an ensemble 
method that combines weak classifiers in a weighted manner to form a 
strong classifier, giving more weight to incorrectly classified instances in 
subsequent rounds (Zhuang et al., 2021). Categorical boosting (Cat­
Boost) is a gradient-boosting algorithm that efficiently handles cate­
gorical features by converting them into numerical representations 
during training (Ibrar et al., 2022). These models were applied using 13 
experimental input variables to predict effluent NH4
+-Nout and TNout in 
the MBR.
2.3.2. Bayesian optimization

Fine-tuning the hyperparameters of each model using Bayesian 
optimization improves performance while reducing computational 
costs. It builds a probabilistic model, typically a Gaussian process, to 
predict the performance of different hyperparameter configurations, 
guiding the selection of optimal values through a balance of exploration 
and exploitation (Shi et al., 2021; Yin and Li, 2022). The search space for 
hyperparameters, such as learning rate, tree depth, and iteration num­
ber, was defined based on prior knowledge and preliminary results. 
Compared to grid and random search, Bayesian optimization explores 
the parameter space more efficiently, achieving better results with fewer 
evaluations. Comparative experiments with stochastic and grid search 
confirmed that Bayesian optimization outperformed these traditional 
methods in terms of both accuracy and computational efficiency, mak­
ing it the most suitable choice for our specific application.

2.3.3. K-fold cross-validation

For model validation, K-fold cross-validation was employed to 
reduce bias and ensure stability across the datasets. This approach splits 
the data into k (k = 10) equally sized portions. Designate one portion as 
the test set for each iteration while using the remaining portions for 
training. This procedure is repeated k times, ensuring each subset is 
precisely set once as the test (Fushiki, 2011; Zhang and Liu, 2023). The 
average performance across all folds provides a robust measure of the 
model’s generalization ability, reducing overfitting and variance in our 
results.
2.3.4. Implementation of machine learning models

The models were implemented using Python 3.11.4 and scikit-learn 
libraries. The datasets were preprocessed to ensure compatibility with 
each algorithm, including scaling and encoding as necessary. Each 
model was trained using optimized hyperparameters obtained from 
Bayesian optimization, and cross-validated results were used to ensure 
consistency in model performance evaluation.
