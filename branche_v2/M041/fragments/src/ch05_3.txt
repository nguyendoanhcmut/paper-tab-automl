ANN description
A computer model modeled after the structure and operation of biological neural networks is known as an 
ANN. It comprises several neurons, or networked processing units, that cooperate to resolve challenging issues. 
An ANN with many layers of neurons, including an input layer, one or more hidden layers, and an output layer, 
is called a multilayer perceptron (MLP). To reduce the error between the expected and actual outputs, the MLP 
is trained using a backpropagation technique that adjusts the weights of the connections between neurons34.
The high processing demands of modern deep learning architectures can be avoided using the MLP, one of 
the most basic deep neural networks. An MLP model’s hidden layer count is a hyperparameter that requires 
tuning. An MLP model has an arbitrary number of hidden layers. Some broad rules can be followed, though. A 
good rule of thumb is to start with one hidden layer and increase it until the model no longer performs better. 
Another recommendation is to figure out the optimal number of hidden layers using cross-validation methods. 
Another hyperparameter must be set is the number of neurons in the buried layer. One typical rule of thumb is 
to place a certain number of neurons between the sizes of the input and output layers. Using a neuronal count 
equal to two-thirds of the total input and output layer sizes is another basic guideline35.
The activation function is another hyperparameter that needs to be adjusted in an MLP model. The activation 
function may be used to provide non-linear output from a neuron. A few activation functions that may be used 
in an MLP model include the rectified linear unit (ReLU) function, the hyperbolic tangent function, and the 
sigmoid function. Any input value may be gradually converted to a value between 0 and 1 using the sigmoid 
function. Like the sigmoid function, the hyperbolic tangent function takes any input value and outputs a number 
between − 1 and 1. Any input value less than 0 is mapped to 0 by the non-smooth ReLU function, and any input 
value higher than or equal to 0 is mapped to the input value itself36.
Overfitting is a prevalent issue in machine learning that occurs when a model performs badly on fresh data 
after doing too well on training data. Overfitting happens when a model is too complicated relative to the amount 
of training data available. In other words, the model might remember the training data instead of identifying 
underlying patterns. One strategy to prevent overfitting is to use regularization techniques such as L1 or L2 
regularization. Regularization encourages the model to have lower weights by increasing the penalty term in the 
loss function. This helps avoid overfitting by simplifying the model37.
The use of dropout regularization is another method for preventing overfitting. During training, dropout 
regularization randomly removes some of the network’s neurons. This pushes the model to acquire more robust 
properties and helps prevent it from leaning too much on any one neuron. Overfitting detection can also be 
done using cross-validation methods. Cross-validation assesses the model’s performance on both the training 
and validation data sets. Overfitting may be taking place if the model performs much worse on the validation set 
than it does on the training set38.

input layer, which represents the features or input data to the MLP, is where the flowchart begins. When every 
input layer neuron is connected to the first hidden layer neuron (if applicable), and so on, a completely linked 
architecture is produced. Every neural connection has a certain amount of weight. The weighted sum of the input

an appropriate activation function is utilized for the output layer. A Softmax function is frequently used for 
classification jobs, while an Identity function is commonly utilized for regression activities. The output layer’s 
final outputs represent the MLP predictions (Zhao and Xiao,2021).

of ammonia, nitrogen, and phosphate, as well as the effectiveness of their removal, were the output variables. 
Utilizing historical data from Yi Ding26, MLP was trained and tested. MSE was employed as a performance
