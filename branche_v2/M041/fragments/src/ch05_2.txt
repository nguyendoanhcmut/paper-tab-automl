RSM description
A collection of mathematical and statistical methods known as RSM is used to create, enhance, and optimize 
processes. It is an effective tool for determining the best input variable settings and maximizing the response of a 
process or product. One of the most popular software packages for RSM modeling is Design-Expert. It provides 
an extensive range of design possibilities and a flexible way to handle categorical parameters and combine them 
with mixture and process variables. A combination of RSM and Design-Expert software can be used to screen 
for essential parameters, determine appropriate process settings, and find the perfect formulation with a mixture 
of design30.
RSM is a set of mathematical and statistical methods for creating, refining, and optimizing processes. Multiple 
factors can be studied using RSM, albeit often just two. Running a series of full factorial DOEs allows RSM to 
map the response and provide equations that show how the factors influence the response31.

appreciable variations in the means of two or more groups. ANOVA is used in RSM to assess the importance of

The design of the experimental factors (input variables), represented as X1, X2,., and Xn, is the first step 
in the flowchart. Appropriate levels are chosen for experimentation for each element. A set of experiments 
(Experiments 1 through Experiment n) comprise an experimental design. Every experiment combines different 
levels of particular factors. The experiments are carried out, and each experiment’s corresponding responses 
(output variables) are measured or observed. A response surface model is fitted using the experimentally 
collected data. This model attempts to simulate the connection between the output response variables and the 
input components (X1, X2,., and Xn). The mathematical model for the response surface can be created using 
regression analysis or other modeling methods. The response surface model can be used to identify the ideal 
factor levels that maximize or decrease the response variable if the study’s goal is optimization. It can be validated 
to ensure the model is accurate and reliable in forecasting outcomes for unobserved data points. The process can 
be repeated, or further analysis can be carried out, depending on the precise problem and objectives33.

Using RSM, a mathematical model was created to precisely depict the relationship between the dependent 
variables (ammonia nitrogen concentrations, phosphate concentrations, and removal efficiency) and the 
independent variables (TOC, pH, and time). A Box-Behnken statistical experimental design produced 33 and 
44 experimental runs. The runs in this study manipulated the total organic carbon (TOC) levels, ranging from 
40 to 120 mg/L, the pH levels from 6 to 9, and Time from 0 to 20 days, using a central composite design. This 
design enabled the assessment of how both factors influenced removal efficiency.
