2.2. Logistic regression
Logistic regression (LR) was used to develop binary classification models that estimate the probability of exceeding selected 
effluent ammonium thresholds (NH4–Neff). For each threshold m, the exceedance probability pm is given by Equation (1).

Coefficients α0, …, αi were estimated by maximum likelihood. The model inputs xi were: NLR, PLR, SRT, HRT, Fair, PAR, PARmax, 
DO, DOmax, T, and Tmax. Eight LR models were built using the following NH4–Neff thresholds: 1.6, 4.0, 6.0, 8.0, 10.0, 12.0, 14.0, and 
16.0 mg N⋅ L−1. The selected threshold set and the data distribution were supported by the empirical cumulative distribution function 
(CDF) (Fig. S2).
Prior to model development, the dataset underwent rigorous preprocessing. Incomplete records containing missing values were 
excluded from the analysis. The input data were subjected to min-max standardization to ensure uniform scaling. A Z-score pre- 
screening was performed to identify outliers and potential measurement errors, with Zi=(xi−μi)/σi. All values were within the 
acceptance threshold (Zi = 0.01–2.95 < 3; Table S2), indicating no evidence of measurement errors in the analysed dataset.
The empirical distributions of the input data were evaluated automatically using XLSTAT software. The goodness-of-fit between the 
empirical and theoretical normal distributions was assessed using the Kolmogorov-Smirnov test, applying a critical probability value of 
p = 0.05 (Table S3). For variables where the data distribution significantly deviated from normality, a Box-Cox transformation was 
applied prior to integration into the logistic regression framework."

Model performance was evaluated using accuracy (ACC), sensitivity/recall (SENS), specificity (SPEC), precision (Prec), the area 
under the receiver operating characteristic curve (ROC-AUC), and F1-score. Compliance with each selected NH4–N threshold was 
defined as the positive class. SENS therefore represents the proportion of compliant observations correctly classified, whereas spec­
ificity represents the proportion of non-compliant observations correctly classified. Precision quantifies the proportion of observations 
predicted as compliant that were experimentally compliant, while F1-score represents the harmonic mean of precision and recall. ROC- 
AUC evaluates the model's ability to discriminate between compliant and non-compliant observations across probability cut-offs. The 
equations used to calculate these metrics are provided in Supplementary Information, Section S1. 95% confidence intervals were also 
determined for all performance metrics.
The data selection comprised a total of 230 measurement episodes. To ensure the model generalized across all seasonal and 
operational variations, a stratified random sampling approach was applied. Data from four operational periods were used to identify 
the LR model, with 80% used for training and 20% for testing in each period (1–4), resulting in 210 episodes in which a wide range of 
NH4-Neff values was observed. Model training and validation were performed utilizing 10-fold cross-validation to reduce uncertainty
