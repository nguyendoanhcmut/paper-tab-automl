To construct a reliable daily-scale prediction model for DAF effluent T-P, four representative machine-learning algorithms 
Decision Tree, Random Forest, XGBoost and LightGBM were developed and evaluated. These models were selected to com­
pare different tree-based learning paradigms, including a single interpretable tree structure (Decision Tree), a bootstrap 
aggregation ensemble (Random Forest), a gradient-boosting framework with regularization (XGBoost), and a histogram- 
based gradient-boosting algorithm optimized for large-scale tabular environmental data (LightGBM).
Hyperparameter tuning was performed using a Bayesian optimization framework to efficiently explore the parameter 
space while minimizing computational cost. The search space for each model followed the ranges summarized in 
Table 2. For all models, the objective was to minimize the mean squared error (MSE) between observed and predicted efflu­
ent T-P concentrations.
